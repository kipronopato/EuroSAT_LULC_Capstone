# EuroSAT imagery attribution

These sample GeoTIFFs are from the EuroSAT multispectral dataset by Patrick Helber, Benjamin Bischke, Andreas Dengel, and Damian Borth. The PNG previews convert Sentinel-2 reflectance to 8-bit true colour. The demo mosaic joins held-out patches and includes a derived label image. The project slides and reports include imagery derived from the same dataset. Contains modified Copernicus Sentinel data.

See the [EuroSAT project and dataset citation](https://github.com/phelber/EuroSAT) and the accompanying [MIT license](EUROSAT_LICENSE.txt).
